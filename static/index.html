水库防汛调度与闸门执行批次

授权时冻结每孔开度目标，逐孔登记实际开度；拒动留执行中、恢复只续办剩余孔；全部孔一致到位且无未关闭事项，总工才能关闭。

  1. draft → checked → authorized：值班员复核、总工授权。
  2. POST /api/items/{id}/batch/authorize：总工冻结每孔目标，指令进入 executing。
  3. POST /api/items/{id}/batch/dispatch：调度员派工。
  4. POST /api/items/{id}/batch/receipts：值班员逐孔回执（同孔并发先到生效；client_token 防重试重复）。
  5. 拒动 / 回传失败：feedback-lost 后 batch/continue 同批次续办，已到位不重做。
  6. 库位变化：batch/recompute 只重算未到位孔，已到位保留。
  7. batch/settle 全部一致到位 → executed；batch/close 总工关闭。
使用 X-Actor 和 X-Role 请求头调用接口。
